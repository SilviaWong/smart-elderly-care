# 智慧养老管理系统设计交付包

## 文件
- `PRD.md`：产品需求文档，覆盖目标、范围、角色、业务规则、功能清单、流程、状态机、非功能需求和验收标准。
- `ER设计.md`：逻辑 ER 图、实体关系、索引与物理模型设计原则。
- `schema.sql`：MySQL 8.0 初始建表脚本，包含系统、档案、入住、工单、健康、护理、餐饮、财务、IoT、风险、报表与监管相关表。

## 使用顺序
1. 先评审 PRD 的范围和待确认事项。
2. 再评审 ER 关系和关键约束。
3. 在开发库执行 `schema.sql`。
4. 基于数据库结构生成 Entity / Mapper，再开发 Service 和 Controller。
5. 对床位并发、护理任务幂等、收款幂等、机构数据隔离编写集成测试。

## 重要声明
本交付包是依据用户提供的项目介绍整理的复刻设计方案。原始资料未提供源码、原数据库 DDL、API 文档和完整业务规则，因此本设计中的字段、关系、状态机和技术实现均属于本次工程化设计，不应描述为原项目既有实现。
