# 智慧养老管理系统｜Codex 分阶段开发任务清单

> 版本：V1.0  
> 开发策略：模块化单体、先 P0 核心闭环，再扩展 P1/P2。  
> 使用原则：每次向 Codex 下达一个阶段任务；验收通过后再进入下一阶段。

## 项目范围基线

- 前端：Vue 3 + TypeScript + Vite + Element Plus + Pinia + Vue Router + Axios
- 后端：Java 17 + Spring Boot 3.2.8 + Maven + Spring Security + JWT + MyBatis-Plus
- 数据库：MySQL 8.0
- 架构：前后端分离、模块化单体
- 初始数据库脚本：47 张表（以当前 `schema.sql` 为准）
- 核心 P0：系统管理、老人档案、入住床位、服务工单、健康记录、护理计划/任务、风险事件
- P1：健康预警增强、餐饮、财务、IoT、运营报表/异步导出
- P2：监管报送扩展、家属端、真实设备协议或其他外部集成（需另行确认）
